# 实测结论

## 1. 根因与修改结果

旧版不是 Gemini 本身“不会理解”，而是产品规则把自然回答推向固定教学任务：

- `MUST give one immediately useful Chinese sentence` 让职业规划问题直接跳成一句话教学。
- `expectsChineseTeaching()` 只要看到 China、Mandarin 或汉字就可能要求中文卡片。
- 缺卡时第二次 Repair 会覆盖第一次合理回答；旧版保姆场景实际出现 2 次模型调用。
- 强结构化输出让模型优先满足卡片，而不是先回答学生。

最终版本删除以上强制链。主回答只有一次模型调用和自由文本流；卡片只从明确教学行中保守提取，按需拆词才使用一次独立轻量调用。

## 2. 旧版 vs 最终版真实证据

| 场景 | 旧版真实行为 | 最终版真实行为 | 判断 |
|---|---|---|---|
| Waiter 规划 | “我们可以聚焦餐厅常用基础表达。请跟我说……” | 先给分阶段职业学习方案，再让学生选择优先项 | 意图理解明显改善；仍有“先学问候”的通用模型倾向 |
| 工厂操作员 | 直接教“机器坏了” | 明确接受“不从问候开始”，列机器指令、安全、报障三类并询问实际高频指令 | 不再擅自开始跟读 |
| 司机 | 直接给机场句并问“要不要练习” | 先确认机场任务，让学生选择最需要的表达 | 更自然，但可再更主动提供场景方案 |
| 收银员 | 直接给答案，未进入用户要求的角色扮演 | 立即以买家身份说“这里可以用 QRIS 支付吗？” | 正确跟随角色扮演意图 |
| 家庭保姆 | 直接教“我要打扫房子”并要求复述 | 先按清洁、洗衣、做饭组织需求并让学生选择 | 不再强制一句话训练 |
| 不想学习 | 允许普通印尼语聊天 | 允许普通印尼语聊天，无中文卡片 | 保持正常 |

评分（基于上述 6 个同类场景，5 分制人工证据评分）：

| 维度 | 旧版 | 最终版 |
|---|---:|---:|
| 当前意图理解 | 2.7 | 4.2 |
| 自然交流 | 2.5 | 4.0 |
| 职业针对性 | 3.0 | 4.0 |
| 是否避免强制练习 | 2.0 | 4.5 |
| 角色/话题跟随 | 3.0 | 4.3 |

## 3. 极简 Prompt vs 完全无教学规则

同模型、同参数、8 组相同输入：

| 指标 | 无 System Prompt | 最小身份 Prompt |
|---|---:|---:|
| 成功调用 | 8/8 | 8/8 |
| 总输入 Token | 220 | 1,652 |
| 总输出 Token | 5,827 | 2,024 |
| 平均总 Token/轮 | 756 | 460 |
| 平均延迟 | 6,094 ms | 3,421 ms |
| 总模型成本 | $0.014634 | $0.005556 |
| 推算 20 轮 | $0.036584 | $0.013889 |

完全无 Prompt 能理解多数职业问题，但经常输出 900 Token 长清单；A1 还把含糊的 `res` 直接猜成 résumé。最小身份 Prompt 的回答更短、更像印尼语学习助手，也避免了发音评分和强制教学，成本降低约 62%。因此保留极简身份层优于完全裸模型。

## 4. 拆词、上下文与语音

- `小明爱我` 按需拆为 `小明｜Xiǎo Míng｜人名`、`爱｜ài｜cinta/sayang`、`我｜wǒ｜aku/saya`；未机械拆开人名。
- 连续对话能正确解释 `爱`，正确反转为 `我爱小明`，切换到食物话题后仍保留更早两句学习引用。
- 对 `Yang tadi di atas`，最终版没有擅自选一句，而是同时列出两个合理候选并要求学生指出目标。
- 更含糊的 `kata berdua` 场景仍会提出一个候选后再确认，属于部分通过；真实学生测试应继续观察，但没有脱离历史去解释普通印尼语 `berdua`。
- 完整句与三个词共 5 次真实 TTS 均返回 `audio/mpeg`、`zh-CN-XiaoxiaoNeural`；第二次相同整句为 `HIT`，从 1,237 ms 降至 503 ms。
- 390×844 与桌面浏览器共 12/12 检查通过，无水平溢出；正文、原卡片、完整句和逐词 TTS 均可播放。

## 5. 性能与成本

最终 Preview 的 14 次主对话：

- 输入 6,449 Token，输出 3,031 Token，平均 677 Token/轮。
- 首字 P50 1,095 ms，P95 3,092 ms；完整回答平均 2,713 ms。
- 总成本 $0.009512，平均 $0.000679/轮，推算 20 轮 $0.013589。
- 按需拆词仅在点击时调用：625 输入 + 162 输出 Token，1,761 ms，$0.0005925。

与旧版 6 个同类首轮场景相比，平均总 Token 从 770 降至 407（-47%）；平均完整响应从 2,280 ms 到 2,730 ms（+20%），平均成本从 $0.000501 到 $0.000554（+11%）。增加的输出是自然规划与解释内容，不是 Repair；需在真实学生测试继续监控长回答，尤其 waiter 规划仍可能生成较长清单。

## 6. 仍需真实学生验证的边界

- Gemini 自身有把职业学习计划写成“先问候、再数字”的通用教学倾向；这不是代码强制，继续加特殊 Prompt 会再次走向机械规则，因此本版保留为可观察风险。
- 主模型可能主动按单字解释；产品的“拆词”结果已按自然词单位纠正展示，但不改写模型正文。
- 含糊指代已改为候选澄清；非常口语化、语法不完整的印尼语仍可能先猜一个候选再确认。
- 本轮没有宣称发音评分、实时语音轮次、长期记忆或掌握度判断已实现。
