# Deployment Checklist — Commercial Accounts

- [ ] Clean working tree reviewed; only approved files are included.
- [ ] TypeScript and production build pass.
- [ ] Preview deployed from the approved commit only.
- [ ] Preview environment variables match the intended non-production scope.
- [ ] Human Preview QA signs off.
- [ ] Production deployment is explicitly approved by the product owner.
- [ ] Post-deployment HTTP and authentication smoke tests pass.
- [ ] No production deployment is created before the preceding items are checked.
