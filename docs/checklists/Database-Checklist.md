# Database Checklist — Commercial Accounts

- [ ] Schema and Phase 2 migration are applied in order.
- [ ] RLS is enabled on account tables.
- [ ] Service-role grants are present only for server-side access.
- [ ] Membership plans and server-side permissions are seeded.
- [ ] Roles and role permissions are seeded.
- [ ] One active device index is present.
- [ ] Session, login history, audit, expiry, and soft-delete behavior are tested.
- [ ] Backup and restore plan is approved before production migration.
