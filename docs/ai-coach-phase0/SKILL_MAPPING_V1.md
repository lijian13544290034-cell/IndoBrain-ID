## Ambiguities requiring confirmation

- S02's absolute “core action” language must become a conditional strategy before runtime use.
- S03's fixed five-step, only-upward/no-skip wording conflicts with adaptive learner needs.
- S07's “sole mastery criterion” wording conflicts with the current five-dimensional mastery model.
- The source is prose, not an authoritative machine-readable manifest; every row remains pending human review.
