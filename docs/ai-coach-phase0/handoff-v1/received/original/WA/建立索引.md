本目录为 IndoBrain / 尼会说 **AI Teaching Skills Library V1** 研究成果，独立于 IndoBrain 代码仓库，未提交 Git。

## 三份交付文档

| 文件 | 内容 | 规模 |
|---|---|---|
| `1-IndoBrain-AI-Teaching-Skills-V1.md` | 主规范：12 个 Teaching Skill，每个 12 字段；含总则、能力图谱、Skill 编排、产品门禁 | 约 12 个 Skill × 12 字段 |
| `2-教学证据与参考文献表.md` | 证据台账：来源、作者、年份、研究对象、主要发现、适用边界、原始链接；证据分级与不可引用清单 | 40+ 条来源 |
| `3-双向教学示例库.md` | 中文教学 / 印尼语教学双轨示例，逐 Skill 的对错样例与失败案例 | 12 Skill × 双语示例 |

## 阅读顺序建议

1. 先读 `1-` 的「总则」与「证据分级约定」——它定义了本文档中所有 `[强证据]` / `[有限证据]` / `[假设]` 标记的含义。
2. 再读 `2-` 的「不可引用清单」——它列出被二手博客广泛误传但原始研究不支持的说法，避免后续被写进产品文案。
3. 工程落地时以 `1-` 每个 Skill 末尾的「自动化验收条件」为唯一验收口径。
4. 内容生产（课程脚本、教练话术）以 `3-` 为准，不以 `1-` 中的示例为准（`1-` 的示例为示意，`3-` 为定稿语气）。

## 重要限制

- 本 V1 是**研究产出**，不是产品决策。标注 `[假设]` 的条款尚未被任何实证研究直接验证，进入产品前必须做 A/B 或小样本测试。
- 所有引用均可追溯到原始出版方或 DOI。**未使用任何二级博客转述的效应量数字**。
- 本文档不涉及 IndoBrain 现有课程正文、不做课程内容判断，只描述「教练该如何教」。
