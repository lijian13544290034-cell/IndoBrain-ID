## GROUP 36 — GROUPING_REVIEW_REQUIRED

CATEGORY: 高频基础

SUBCATEGORY: 常见描述

CURRENT CONCEPTS:

- ingat
- lupa
- harga
- mahal
- murah
- diskon
- tunai
- cash

WHY GROUPING IS WEAK:

`ingat` and `lupa` belong to memory / cognitive-state language. `harga`, `mahal`, `murah`, `diskon`, `tunai`, and `cash` belong to price and payment language. These two semantic clusters do not form one natural beginner learning block.

If we force coverage, the Real Use unit would either:

- ignore `ingat / lupa`, or
- produce unnatural shopping sentences that only exist to include the target words.

SUGGESTED REGROUPING:

1. Memory / cognition group:
   - ingat
   - lupa
   - tahu
   - ngerti
   - paham

2. Money / shopping payment group:
   - harga
   - mahal
   - murah
   - diskon
   - tunai
   - cash
   - kembalian
   - transfer
   - QRIS

IMPACT:

No immediate implementation change. For Real Use V1, Group 36 keeps only the natural price/payment sentences:

- Harganya berapa? — 价格多少？
- Mahal banget. — 太贵了。
- Bisa cash? — 可以现金吗？

`ingat / lupa` should not be forced into this Real Use Unit.

RECOMMENDED ACTION:

Defer actual regrouping to a future Basic Essentials content-structure task. Do not change the 633 Concepts in this content-design pass.
